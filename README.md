# adecordi.github.io

## Strumenti

- [**C.A.R.T.A.**](pdf/) (Compila Automaticamente Righe, Testi e Anagrafiche): lettore di PDF e P7M; apre, verifica e stampa PDF e documenti firmati digitalmente (`.p7m`, `.tsd`, `.m7m`), con vista leggibile delle fatture elettroniche (FatturaPA). Funziona nel browser, anche offline, e i file non lasciano mai il dispositivo. Disponibile anche come [componente aggiuntivo di Outlook](pdf/outlook/).
